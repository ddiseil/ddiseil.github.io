# DISEIL project page

Source of https://ddiseil.github.io/ (static HTML, no build step).

- `index.html` page
- `css/style.css` styles
- `js/teaser.js` the looping method animation
- `js/chart.js` the interactive results chart (Table 1 values are in `#table1` in `index.html`)
- `js/site.js` before/after clips in step, BibTeX copy button

Preview locally with `python3 -m http.server` in this folder.
