# DISEIL project page

Source of https://ddiseil.github.io/ : static HTML, CSS and JavaScript, no build step.

- `index.html` page text and structure; the numbers behind the results chart (Table 1 of the paper) are in `#table1`
- `css/style.css` layout and type
- `js/loop.js` the running method animation (canvas, one clock shared by every view)
- `js/site.js` page behaviour: synced videos, results chart, enlarged figures

Preview locally with `python3 -m http.server` in this folder.
